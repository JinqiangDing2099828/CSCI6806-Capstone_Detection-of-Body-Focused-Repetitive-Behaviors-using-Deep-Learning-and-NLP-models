# Plots

This folder contains all figures generated during data analysis, model training, and evaluation.

## Structure

Subfolders correspond to different parts of the project, for example:

- `eda/` – figures generated during exploratory data analysis  
- `evaluation_plots/` – model performance comparison plots  
- `bfrb_vs_nonbfrb_modality_plots/` – modality comparison visualizations after FFT
- `fft_mlp_all/`, `model4/`, `model3_cnn/`, etc. – model-specific outputs  

## Notes

All of the plots in this folder are automatically generated by the notebooks and saved during execution.

They are included in the repository to make the results easier to review without re-running all notebooks.  

All figures can be regenerated by running the corresponding notebooks in the `notebooks/` directory.
